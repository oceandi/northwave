NORTHWAVÉ · THE WALK

From an empty folder to a game that makes sound — in five steps.

Northwavé is a sound development kit: it turns a game's sound design into a request list a person can answer with a microphone. This is the whole walk, exactly as the program teaches it.

Step 0 · The folder

Open a folder. That is a project.

⌘O or File ▸ Open Folder… — any folder on your disk. Northwavé makes no database and asks for no account: the project is the folder, and it stays yours. Drop your existing recordings anywhere inside; the explorer on the left shows the folder exactly as the Finder would — green means a recording is used by the book, grey means it is waiting.

Step 1 · The tree

The tree asks. You record.

Every sound the game needs is a named slot with a reason attached — what to record, how to record it, and why it matters. Pick a branch and read its card. Then either right-click a slot ▸ Record Now (the take is born where it will live, named for the slot that asked), or drag a file you already have onto it. Red is needed; green is delivered; the bar at the top only moves when a sound truly lands.

a branch asks for thirty unbroken seconds of a room doing nothing — and says why
Step 2 · The table

One plain-text table and a clock.

The whole design is one readable file — table.csv — six columns: page, thing, when, level, bank, words. When is a menu, not an exam: loops for beds, plays for acts, on for events, follows for ladders, while, door, radio. Beds sit at 0.5; acts speak at 1.0. A person can read it; so can an engine. Nothing locks.

the book — every row a promise the game can keep
Step 3 · Hearing

Double-click anything. Stop everything with one key.

Double-click a recording to hear it — through the same mixer the game will use, never a second player, so what you audition is what will ship. The console (top right) carries the transport: what is sounding, for how long, and a stop. ⌘. is Everything Off, always. WAV and Ogg Vorbis both open; loop points travel in WAV's smpl chunk.

Step 4 · The kit

Hand it to a game.

⌘E or File ▸ Hand It to a Game… — Northwavé writes a folder a game can read. The README that travels with it lists, honestly, everything that is still missing or wrong: a kit carries its own faults, so the programmer three weeks from now reads a sentence instead of debugging a mystery.

the tree will not pretend: silent rows are named before they ship
First Light kit/
├─ table.csv — the book, as plain text
├─ sounds/ — every recording the table names, once each
├─ core/ — the engine: one C header, one static lib, one wasm
├─ adapters/ — unity · unreal · godot · wwise · fmod
├─ play.html — the whole kit, playable in a browser, no install
└─ README.txt — what this kit is, and what is wrong with it
Step 5 · Unity

One drag, one menu, press Play.

Drag the exported kit folder into Assets. That is the whole install: the kit carries its own scripts, its own editor menu, and the native core. Then one menu item — Northwave ▸ Set up the demo — builds a world around your table: grounds, a walker, a car. Press Play. Footsteps come from your footstep bank; the beds are your rooms; the curtain plays your films first.

voices: 1 — the same table, the same recordings, now inside a game engine

The same kit binds to Unreal, Godot, Wwise and FMOD through the adapters folder — and play.html plays it in a browser with nothing installed at all.
